Web technologies

HTML

HTML is hyper text markup language. the browser recieves the HTML file and renders the web page. HTML is pure text based.

CSS

CSS is a style sheet language. it is used to define the visual presentation, design, and layout of webpages. unlike HTML, css acts as a styling layer.

Javascript

Javascript is a lightweight, interpreted programming language. it is primarily used to create interactive content on websites. along with CSS and HTML, Javascript is one of the 3 core languages.
